## Deploy on Netlify

The Next.js app lives at the repository root. The root `netlify.toml` sets
`base = "."`, runs `npm ci --include=dev && npm run build`, and publishes `.next`. Netlify automatically
detects Next.js and configures its runtime.

The explicit install uses `package-lock.json` and includes build tools, even
when a CLI deploy starts without dependencies installed. Keep the lockfile
committed and update it whenever dependencies change.

Keep the base directory set to `.` in this file. Do not use build-machine paths
such as `/opt/build` or a nonexistent subdirectory such as `kavyackers`.
The committed configuration overrides the saved base directory in Netlify's
site settings so fresh deployments use the same repository-relative paths.
